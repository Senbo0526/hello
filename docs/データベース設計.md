# データベース設計

作成日: 2026-10-04

---

## ER図

```
┌─────────────────────────────┐       ┌──────────────────────────────────┐
│           columns           │       │              cards               │
├──────────────┬──────────────┤       ├──────────────┬───────────────────┤
│ id           │ INTEGER (PK) │       │ id           │ INTEGER (PK)      │
│ title        │ TEXT         │ 1   N │ column_id    │ INTEGER (FK)      │
│ position     │ INTEGER      │───────│ title        │ TEXT              │
│ created_at   │ DATETIME     │       │ description  │ TEXT (NULL可)     │
└──────────────┴──────────────┘       │ due_date     │ DATE (NULL可)     │
                                      │ priority     │ TEXT (NULL可)     │
                                      │ position     │ INTEGER           │
                                      │ created_at   │ DATETIME          │
                                      │ updated_at   │ DATETIME          │
                                      └──────────────┴───────────────────┘
```

---

## テーブル定義

### columns テーブル

| カラム名 | 型 | 必須 | デフォルト | 説明 |
|---------|-----|------|-----------|------|
| id | INTEGER | ✓ | AUTO INCREMENT | カラムの一意識別子（主キー） |
| title | TEXT | ✓ | — | カラムのタイトル |
| position | INTEGER | ✓ | 0 | カラムの表示順（0始まり） |
| created_at | DATETIME | ✓ | 現在日時 | レコード作成日時 |

### cards テーブル

| カラム名 | 型 | 必須 | デフォルト | 説明 |
|---------|-----|------|-----------|------|
| id | INTEGER | ✓ | AUTO INCREMENT | カードの一意識別子（主キー） |
| column_id | INTEGER | ✓ | — | 所属カラムのID（外部キー） |
| title | TEXT | ✓ | — | カードのタイトル |
| description | TEXT | — | NULL | カードの詳細説明 |
| due_date | DATE | — | NULL | タスクの期限日 |
| priority | TEXT | — | NULL | 優先度（`high` / `medium` / `low`） |
| position | INTEGER | ✓ | 0 | カラム内での表示順（0始まり） |
| created_at | DATETIME | ✓ | 現在日時 | レコード作成日時 |
| updated_at | DATETIME | ✓ | 現在日時 | レコード最終更新日時 |

---

## リレーション

- `columns` と `cards` は **1対多** の関係
- `cards.column_id` は `columns.id` を参照する外部キー
- カラムを削除すると、そのカラムに属するカードも連鎖削除される（`ON DELETE CASCADE`）

---

## フィールド補足

| テーブル | フィールド | 補足 |
|----------|-----------|------|
| columns | position | カラムの表示順（0始まりの整数） |
| cards | priority | `'high'` / `'medium'` / `'low'` のいずれか |
| cards | position | カラム内でのカードの表示順（0始まりの整数） |
| cards | updated_at | カード更新のたびにアプリ側で現在日時に更新する |
