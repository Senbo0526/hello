# 技術スタック

作成日: 2026-10-04

---

## 使用技術

| 項目 | 内容 |
|------|------|
| フロントエンド | HTML5 / CSS3 / JavaScript（ES6+） |
| フレームワーク | なし（バニラJS） |
| バックエンド | Node.js / Express |
| データベース | SQLite |
| DBライブラリ | better-sqlite3（または sqlite3） |
| 実行環境 | Node.jsサーバーを起動してブラウザからアクセス |

---

## 技術選定の理由

| 技術 | 選定理由 |
|------|---------|
| バニラJS | フレームワークに頼らずDOM操作・イベント処理の基礎を習得するため |
| Node.js / Express | フロントエンドと同じJavaScriptで統一でき、学習コストが低いため |
| SQLite | ファイル1つで動作し、サーバー起動が不要。学習用途に最適なため |
| better-sqlite3 | 同期APIで扱いやすく、Node.js初学者に向いているため |

## ファイル構成

```
trello-app/
├── server/
│   ├── index.js          # Expressサーバー起動・ルーティング
│   ├── db.js             # SQLite接続・初期化
│   └── routes/
│       ├── columns.js    # カラム関連APIルート
│       └── cards.js      # カード関連APIルート
├── public/
│   ├── index.html        # ページ構造・モーダルHTML
│   ├── style.css         # スタイル定義
│   └── app.js            # フロントエンドロジック（fetch APIでサーバーと通信）
├── docs/                 # 設計ドキュメント
├── database.sqlite       # SQLiteデータベースファイル（自動生成）
└── package.json
```

---

## 起動方法

```bash
# 依存パッケージのインストール
npm install

# サーバー起動
node server/index.js

# ブラウザでアクセス
http://localhost:3000
```
