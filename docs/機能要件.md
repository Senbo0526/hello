# 機能要件

作成日: 2026-10-04

---

## 機能一覧

### カラム（Column）

| 機能 | 説明 |
|------|------|
| カラム表示 | 複数のカラムを横並びに表示する |
| カラム追加 | ヘッダーの「+ カラム追加」ボタンで新規カラムを追加する |
| カラム削除 | カラム右上の「×」ボタンでカラムを削除する（配下カードも削除） |
| タイトル編集 | カラムタイトルをクリックしてインライン編集できる |

### カード（Card）

| 機能 | 説明 |
|------|------|
| カード表示 | 各カラム内にカードを一覧表示する |
| カード追加 | カラム下部の「+ カード追加」からタイトルを入力して追加する（Enter確定） |
| カード削除 | カードホバー時に表示される「×」ボタンで削除する |
| カード詳細編集 | カードをクリックするとモーダルが開き、詳細を編集できる |

### カード詳細（Modal）

| 項目 | 説明 |
|------|------|
| タイトル | タスクのタイトルを編集する |
| 説明文 | 自由記述のテキストエリア（任意） |
| 期限日 | 日付ピッカーで設定。期限切れの場合は赤文字で表示 |
| 優先度 | 高 / 中 / 低 の3段階。カードの左ボーダー色で視覚的に区別 |

### ドラッグ&ドロップ

| 機能 | 説明 |
|------|------|
| カード移動 | HTML5 Drag and Drop API でカードをカラム間で移動できる |
| ハイライト表示 | ドラッグ中、ドロップ先カラムをハイライト表示する |
| DB更新 | ドロップ時に `PUT /api/cards/:id/move` を呼び出しDBを更新する |

### 非機能要件

| 項目 | 内容 |
|------|------|
| レスポンシブ | ボードは横スクロール対応。カラムは固定幅（272px） |
| ダークモード | OS設定に応じて自動切換え（`prefers-color-scheme: dark`） |
| 対応ブラウザ | モダンブラウザ（Chrome / Edge / Firefox / Safari） |

---

## 初期状態

アプリ初回起動時に以下3カラムをDBに自動生成する：

1. **Todo** — 着手前のタスク
2. **In Progress** — 作業中のタスク
3. **Done** — 完了したタスク

- カード間の並び替え（カラム内での順序変更）

- ユーザー認証・複数人利用対応
