## ユースケース

### UC-01: 新しいタスクを追加する

- **アクター:** ユーザー
- **事前条件:** バックエンドサーバーが起動しており、少なくとも1つのカラムが存在する
- **主フロー:**
  1. 追加したいカラム下部の「+ カード追加」をクリックする
  2. テキスト入力欄にタスクタイトルを入力する
  3. Enterキーを押す
  4. `POST /api/columns/:id/cards` が呼び出されDBに保存される
  5. カードが画面に表示される
- **事後条件:** 新しいカードがカラムに表示され、DBに保存される

---

### UC-02: タスクの詳細を編集する

- **アクター:** ユーザー
- **事前条件:** 編集対象のカードが存在する
- **主フロー:**
  1. 編集したいカードをクリックする
  2. モーダルが開く
  3. タイトル・説明文・期限日・優先度を任意で編集する
  4. モーダル外をクリック、またはモーダルの閉じるボタンを押す
  5. `PUT /api/cards/:id` が呼び出されDBを更新する
- **事後条件:** 変更内容がDBに保存され、カードに反映される

---

### UC-03: タスクを移動・並び替えする（ドラッグ&ドロップ）

- **アクター:** ユーザー
- **事前条件:** 移動対象のカードが存在する
- **主フロー（カラム間移動）:**
  1. 移動したいカードをドラッグする
  2. 移動先のカラムの任意の位置にドロップする
  3. `PUT /api/cards/:id/move` が呼び出されDBの `column_id` と `position` を更新する
  4. カードが移動先カラムの指定位置に表示される
- **主フロー（カラム内並び替え）:**
  1. 並び替えたいカードをドラッグする
  2. 同じカラム内の別の位置にドロップする
  3. `PUT /api/cards/:id/move` が呼び出されDBの `position` を更新する
  4. カードが新しい順序で表示される
- **事後条件:** カードの位置がDBに保存され、画面に反映される

---

### UC-04: カラムを追加・編集する

- **アクター:** ユーザー
- **主フロー（追加）:**
  1. ヘッダーの「+ カラム追加」ボタンをクリックする
  2. `POST /api/columns` が呼び出されDBに保存される
  3. 新しいカラムが右端に追加される
  4. カラムタイトルをクリックして任意の名前に変更する（`PUT /api/columns/:id`）
- **主フロー（削除）:**
  1. 削除したいカラム右上の「×」ボタンをクリックする
  2. `DELETE /api/columns/:id` が呼び出される
  3. カラムと配下のカードがDBから削除される

---

### UC-05: カードをソートする

- **アクター:** ユーザー
- **事前条件:** ソート対象のカラムにカードが存在する
- **主フロー（優先度順）:**
  1. 対象カラムの「優先度順」ボタンをクリックする
  2. フロントエンドがカラム内のカードを高→中→低の順に並び替える
  3. 並び替えた順序で `PUT /api/cards/:id/move` を呼び出しDBを更新する
  4. ソート後もドラッグ&ドロップで自由に順序を変更できる
- **主フロー（期限順）:**
  1. 対象カラムの「期限順」ボタンをクリックする
  2. フロントエンドがカラム内のカードを期限日が近い順に並び替える（期限なしは末尾）
  3. 並び替えた順序でDBを更新する
- **事後条件:** カードが指定の順序で表示され、DBに保存される

---

### UC-06: 期限切れタスクを確認する

- **アクター:** ユーザー
- **事前条件:** 期限日が設定されたカードが存在する
- **主フロー:**
  1. アプリを開く（ページロード時に `GET /api/columns` で全データ取得）
  2. フロントエンドが `due_date` と今日の日付を比較する
  3. 期限切れのカードは期限日を赤文字で表示する
- **事後条件:** ユーザーが期限切れタスクを視覚的に把握できる

## 操作フロー

### 初回起動時

```
PostgreSQL を起動し trello_db データベースを作成
  └→ ./gradlew bootRun でSpring Bootサーバー起動（ポート8080）
       └→ Flyway が V1__init.sql を自動実行しテーブルを作成
            └→ npm run dev でVite開発サーバー起動（ポート3000）
                 └→ ブラウザで http://localhost:3000 にアクセス
                      └→ GET /api/columns → データなし
                           └→ 初期カラム（Todo / In Progress / Done）をDBに挿入
                                └→ ボードを表示
```

### 2回目以降の起動

```
PostgreSQL・Spring Boot・Vite を起動
  └→ ブラウザで http://localhost:3000 にアクセス
       └→ GET /api/columns → DBからカラム・カードを取得
            └→ 保存済みのボードを表示
```

### カード追加フロー

```
「+ カード追加」クリック
  └→ テキスト入力欄を表示
       ├→ タイトル入力 → Enter
       │    └→ POST /api/columns/:id/cards
       │         └→ DB INSERT → カードをDOMに追加
       └→ 何も入力しない / Escキー → キャンセル
```

### カード詳細編集フロー

```
カードをクリック
  └→ モーダルを開く
       └→ 各フィールドを編集（タイトル / 説明 / 期限日 / 優先度）
            └→ モーダルを閉じる（外クリック or 閉じるボタン）
                 └→ PUT /api/cards/:id
                      └→ DB UPDATE → カードの表示を更新
```

### ドラッグ&ドロップフロー

```
カードをドラッグ開始
  └→ ドラッグ中カードを半透明表示
       └→ カード上にホバー → 上半分/下半分で挿入位置インジケーター（青ライン）を表示
            ├→ カード上でドロップ（カラム間 or カラム内）
            │    └→ PUT /api/cards/:id/move
            │         └→ DB UPDATE（column_id・position を更新）
            │              └→ カードを指定位置に移動
            ├→ カラム空白エリアでドロップ → 末尾に追加
            └→ 元の場所でドロップ / キャンセル → 移動なし
```

### ソートフロー

```
「優先度順」または「期限順」ボタンをクリック
  └→ フロントエンドがカード配列をソート
       └→ ソート後の順序でDOMを更新
            └→ PUT /api/cards/:id/move を各カードに呼び出し position を保存
                 └→ ソート後もドラッグ&ドロップで自由に並び替え可能
```
