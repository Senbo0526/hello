```

│           columns               │       │                cards                 │

│ id           │ BIGINT (PK)      │       │ id           │ BIGINT (PK)           │

                                          └──────────────┴───────────────────────┘
```

## テーブル定義

### columns テーブル

| カラム名 | 型 | 必須 | デフォルト | 説明 |
|---------|-----|------|-----------|------|
| id | BIGINT | ✓ | GENERATED ALWAYS AS IDENTITY | カラムの一意識別子（主キー） |
| title | VARCHAR(255) | ✓ | — | カラムのタイトル |
| position | INTEGER | ✓ | 0 | カラムの表示順（0始まり） |
| created_at | TIMESTAMP | ✓ | NOW() | レコード作成日時 |

### cards テーブル

| カラム名 | 型 | 必須 | デフォルト | 説明 |
|---------|-----|------|-----------|------|
| id | BIGINT | ✓ | GENERATED ALWAYS AS IDENTITY | カードの一意識別子（主キー） |
| column_id | BIGINT | ✓ | — | 所属カラムのID（外部キー） |
| title | VARCHAR(255) | ✓ | — | カードのタイトル |
| description | TEXT | — | NULL | カードの詳細説明 |
| due_date | DATE | — | NULL | タスクの期限日 |
| priority | VARCHAR(10) | — | NULL | 優先度（`high` / `medium` / `low`） |
| position | INTEGER | ✓ | 0 | カラム内での表示順（0始まり） |
| created_at | TIMESTAMP | ✓ | NOW() | レコード作成日時 |
| updated_at | TIMESTAMP | ✓ | NOW() | レコード最終更新日時 |

---

## リレーション

- `columns` と `cards` は **1対多** の関係
- `cards.column_id` は `columns.id` を参照する外部キー
- カラムを削除すると、そのカラムに属するカードも連鎖削除される（`ON DELETE CASCADE`）

---

## フィールド補足

| テーブル | フィールド | 補足 |
|----------|-----------|------|
| columns | position | カラムの表示順（0始まりの整数） |
| cards | priority | `'high'` / `'medium'` / `'low'` のいずれか。CHECK 制約で保護 |
| cards | position | カラム内でのカードの表示順（0始まりの整数） |
| cards | updated_at | カード更新のたびに `NOW()` で自動更新（トリガーまたはアプリ側で設定） |

## Flyway マイグレーション（V1__init.sql）

```sql
CREATE TABLE columns (
    id         BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    title      VARCHAR(255) NOT NULL,
    position   INTEGER NOT NULL DEFAULT 0,
    created_at TIMESTAMP NOT NULL DEFAULT NOW()
);

CREATE TABLE cards (
    id          BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    column_id   BIGINT NOT NULL REFERENCES columns(id) ON DELETE CASCADE,
    title       VARCHAR(255) NOT NULL,
    description TEXT,
    due_date    DATE,
    priority    VARCHAR(10) CHECK (priority IN ('high', 'medium', 'low')),
    position    INTEGER NOT NULL DEFAULT 0,
    created_at  TIMESTAMP NOT NULL DEFAULT NOW(),
    updated_at  TIMESTAMP NOT NULL DEFAULT NOW()
);
```
