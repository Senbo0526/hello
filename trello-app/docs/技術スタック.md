## 使用技術

| フレームワーク | React 18 |

| ビルドツール | Gradle |

| DBマイグレーション | Flyway |

### データベース

| 項目 | 内容 |
|------|------|
| RDBMS | PostgreSQL 16 |

## 技術選定の理由

| 技術 | 選定理由 |
|------|---------|
| Java 21 + Spring Boot 3 | 業務システム開発で広く採用されており、REST API構築・DI・JPA など実践的なバックエンド開発を習得できるため |
| Gradle | Spring Initializr のデフォルト対応ビルドツール。Kotlinベースの DSL で可読性が高く、ビルドが Maven より高速なため |
| React 18 | コンポーネント指向の UI 構築・状態管理・イベントハンドリングなどフロントエンド開発の標準を習得できるため |
| Vite | 開発サーバーの起動が高速で、React プロジェクトのビルド・HMR 体験が優れているため |
| Axios | fetch API より簡潔にリクエスト/レスポンスを扱えるため。インターセプターでのエラーハンドリングも容易 |
| Spring Data JPA | SQLを直書きせずエンティティとリポジトリでDB操作を抽象化でき、ORM の概念を習得できるため |
| Flyway | SQLファイルでマイグレーション管理ができ、スキーマ変更を安全にバージョン管理できるため |
| PostgreSQL 16 | 本番環境でも広く採用されるRDBMS。JSON型・全文検索・高度なインデックスなど機能が豊富。SQLite との違いを通じてサーバー型DBの理解を深めるため |

## 起動方法

### バックエンド

```bash
# PostgreSQL を起動し、データベースを作成
psql -U postgres -c "CREATE DATABASE trello_db;"

# バックエンド起動（Flyway が自動でスキーマを作成）
cd backend
./gradlew bootRun

# API サーバーが http://localhost:8080 で起動
```

### フロントエンド

```bash
cd frontend
npm install
npm run dev

# 開発サーバーが http://localhost:3000 で起動
# /api へのリクエストは Vite のプロキシで localhost:8080 に転送
```
