# 画面設計

作成日: 2026-10-04

---

## 画面構成

本アプリはシングルページアプリケーション（SPA）であり、ページ遷移は発生しない。
「ボード画面」と「カード詳細モーダル」の2つの状態で構成される。

## 画面遷移図

```
アプリ起動
  └→ ボード画面（メイン）
        ├→ カードをクリック
        │    └→ カード詳細モーダル（オーバーレイ表示）
        │          └→ 閉じるボタン or モーダル外クリック
        │                └→ ボード画面に戻る
        │
        ├→ 「+ カード追加」クリック
        │    └→ カラム内にインライン入力欄を表示
        │          ├→ Enter → カード追加 → ボード画面
        │          └→ Esc / 空Enter → キャンセル → ボード画面
        │
        └→ カラムタイトルをクリック
             └→ インライン編集モード
                   ├→ Enter / フォーカスアウト → 保存 → ボード画面
                   └→ Esc → キャンセル → ボード画面
```

## UI仕様

### カード表示

| 要素 | 仕様 |
|------|------|
| 左ボーダー色 | 優先度に応じて変化（高: 赤 / 中: 黄 / 低: 緑 / 未設定: グレー） |
| 期限日表示 | カード下部に表示。期限切れは赤文字 |
| 削除ボタン | ホバー時のみ右上に「×」を表示 |

### ダークモード

OS設定（`prefers-color-scheme: dark`）に応じて配色を自動切換え。

### レスポンシブ

- カラムは固定幅（272px）
- カラムが画面幅を超える場合はボードを横スクロール
